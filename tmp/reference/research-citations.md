# Research Citations Index

This file is a top-level bridge to the captured bibliography. It exists so
references can point to `research-citations.md` without assuming a single
monolithic citation file or an external Roko checkout.

## Local Sources

| Source | Use |
|---|---|
| [research-citations/README.md](research-citations/README.md) | Main captured bibliography, topic index, and reading guides |
| [additional-papers.md](additional-papers.md) | Supplemental papers identified outside the captured citation set |
| [v2-depth-research.md](v2-depth-research.md) | Depth-document catalog that names which research areas feed each architecture section |

## Use Rule

Treat paper lists as captured reference context. Before relying on a specific
quantitative research claim in implementation work, open the cited paper or the
relevant topic file and verify the claim in context.
